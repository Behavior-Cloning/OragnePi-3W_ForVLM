# 原始 NPU 输入下的 INT16 两层块误差与性能

本轮完成104个端侧进程，以相同原始 NPU 上游输入比较原版、旧INT16、扩大第二层输入范围的INT16。它定位局部误差，不是完整模型首token结果。100ms目标尚未达到。

## 输入与测试边界

|system正文|system模板|固定前缀|动态正文|动态模板|总输入|仅静态KV复用后的新增|
|---:|---:|---:|---:|---:|---:|---:|
|59|5|64|64|8|136|72|
|123|5|128|256|8|392|264|

34个M16窗口，31个唯一输入SHA；528有效行、16padding行。所有候选每窗口都重新接收原始NPU的hidden/KV，而不是候选自己此前生成的KV。两案例首token相同，重复首token不构成两个独立异常样例。每进程1次预热、2次计时；共208次计时API和104次预热，实际16个端口一致、34份原输出与历史一致、2次A/A一致、104次driver释放为0。
