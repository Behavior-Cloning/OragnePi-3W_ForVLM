# 家庭／桌面陪伴原子动作 128 项

本轮只建设原子动作集合，不纳入组合技能。完整清单见 [ATOMIC_ACTIONS_128.md](ATOMIC_ACTIONS_128.md)，结构化数据见 [atoms.json](atoms.json)。

共128项：头部9，面部表情30，上身与肩部13，单臂24，双臂协调12，手指28，手腕4，陪伴图标8。速度、幅度、时长、同义词不另计动作。左右分支是不同执行器或方向；双臂动作限单个同步姿态或一次手势周期，不能包含场景流程。

机械90项、屏幕38项是设计目录，全部硬件映射尚未验证、板上启用数为0。仅有开发板不等于具备对应头、腰、手臂、灵巧手和屏幕布局。每条给出能力、明确的输出形状、状态/周期区别、起始条件、可能被联动的身体部位与资源互斥；缺少能力时剔除候选，不用其他动作静默替代。

本轮没有新增模型实测或机械执行。旧版35原子+20技能的报告保留在 `../home-companion-rag-20261022`，其TopK与延迟不能归到128项名下。高层指令后续仍限定家庭/桌面陪伴；只有明确不能执行或冲突才判不兼容，条件未定单列，硬件实现状态另列。

## 生成和核验

在本目录执行 `python3 build_catalog.py`，再执行 `python3 validate_catalog.py`。后者验证128个唯一ID、无技能步骤、能力引用、资源、状态、文档完整性和候选哈希；语义去重另外由独立审计完成，不把字符串唯一当成语义唯一。

- `validation.json`：结构检查及左右分支簇。
- `independent-audit.json` / `INDEPENDENT_AUDIT.md`：逐条与跨条审计。
- `experiment-manifest.json`：冻结候选SHA、未进行128项测试的状态。
- `artifact-manifest.json`：交付文件SHA；不包含自身。

以后若修订候选内容，必须重新生成、校验、审计并冻结SHA，不能将修改后的字典与旧排名混用。
