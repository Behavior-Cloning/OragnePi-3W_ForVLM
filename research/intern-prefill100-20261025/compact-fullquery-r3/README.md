# compact-fullquery-r3：完整模型紧凑历史候选

当前目标：prefill约500ms，继续优化decode。实验候选独立于默认部署与已登记最快版本。

- 父版本：outlier8-c448-full-r1，图量化/权重和decode保持该候选；父版本本身改变了L2/L3精度，未获质量推广资格。
- 固定前缀：system正文59/123 +模板5 =64/128；动态正文128/256 +模板8 =实际new136/264。只复用system，不复用上一轮动态内容。
- 存储KV仍448；额外12张两层图为past128/query128。只在请求起点、有效历史1～128、至少128个新增token时运行一次；有效历史全部拷贝，RoPE仍用绝对位置。剩余部分与尾8走现有C448图。
- 按相同完整输入、相同system构建、32个固定反馈token做父版本→候选→父版本重复。额外图会占用内存，真实成本计入负载；不假装同内存占用。
- 这同时改变query分组及空KV槽数，数值可能不同，不能宣称无损；主机掩码/拷贝测试不能代替NPU完整logits比较。
- 语音前端常驻合成录音，RAG仅常驻，无图像/电机/真实麦克风。时延只计模型请求，不含语音链路。
- 36项正式计时，36项来自带标点补齐fixture的自然生成（不是独立质量语料），12项4步完整logits诊断。诊断不计入速度。
- r1/r2为图生成前检查失败（可选parameters字段不存在），无板端结果。r3主机检查抓到keep大于128时未开模板路径的因果mask错误，已修复后才部署；初始失败记录保留。

`compile-status.json`记录12图来源、权重payload/quantizer相等、编译SHA和端口顺序。`build-runtime.json`绑定运行时源码和binary。`host-test.json`覆盖两种K布局、6次ASan/UBSan运行（每次960张mask和258组KV拷贝），包含回退和超长旧历史。

本目录通过测试前不更新最佳指针，完整测试结果写入full-test。样本量每格3，不能当长时间稳定性认证。
