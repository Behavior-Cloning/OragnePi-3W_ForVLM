# Decoder矩阵瓶颈与候选筛选

2026-10-13。局部诊断与单独列出的完整模型五轮结果分别报告，局部探针不能代替全模型或产品验收。诊断输入来自InternVL3-1B全部24层、512历史＋32新增、128步固定反馈运行中的位置544。

普通第0/1层的5份硬件计数：fullconnect占累计busy cycles中位91.555%（91.544–91.566%）。主要大矩阵为MLP gate/up/down。重复编译器UID保留候选层标签，不猜测具体层归属。

这是这一组普通层的归因，不能外推敏感层或500M；busy cycles不能直接相加当成端到端耗时，read counter也不是独立实测DDR带宽。

## 完整DFP候选：精度尚未接受

1B、512＋64、全部24层和完整输出头：导出常量执行门槛通过，但相对原Q8的完整logits L2约12.60%、开发轨迹PPL比1.05738，超过预设1.05质量线。诊断运行写大logits，速度不列为正式成绩；不推广这一候选。

下一版保持W8/A16，只用权重自身搜索DFP小数位，最小化权重均方误差；不查看留出对话。每矩阵记录全部候选的误差和截断比例。既有敏感层、head与KV格式保持基线来源；新版本仍须全模型验证。

转置K与gate/up DFP MSE组合已编译，使用原完整运行捕获输入，仅转换K缓存轴顺序；独立原Q8参考和导出常量参考均与原布局逐字节相同。实板数值/计时只有出现在上表才算完成，不能用编译或数学等价代替设备精度。小图尚不表示全24层收益。

有界MSE缩放候选cap1只搜索权重峰值小数位及其+1，原MSE版最多搜索+6；继续保持W8/A16及原敏感FP16位置。它只读取模型权重、不使用留出样本，目的是检查权重范围对编译执行和误差的影响。编译、单层数学参考或局部计时均不等于全24层达标。

MSE缩放版完整24层已验证：执行门槛通过，L2 4.926%、最低cosine 0.996483；相对原Q8开发轨迹PPL比0.991242、logits L2 9.608%。该结果不等于独立留出通过，五轮干净测速另列。

500M局部probe-gateup-w8dfp：50次两层API平均2.4042ms，执行门槛通过。局部结果不能代替完整32层验收，不与1B混合计算收益。

500M局部probe-gateup-w8dfp-mse：50次两层API平均2.6762ms，执行门槛通过。局部结果不能代替完整32层验收，不与1B混合计算收益。

500M局部probe-all-w8dfp-mse：50次两层API平均2.4630ms，执行门槛通过。局部结果不能代替完整32层验收，不与1B混合计算收益。

## 扩展全部W8矩阵的局部筛选

all-w8dfp-mse只改变原本逐通道W8矩阵的编码，既有DFP V及敏感FP16仍保留。两模型对导出常量的执行门槛通过，但独立原Q8参考暴露出更多权重量化误差。

| 模型 | 两层平均API ms | 对原Q8 hidden L2 | 决定 |
| --- | ---: | ---: | --- |
| intern1b | 3.4768 | 6.831% | 比gate/up MSE局部略快，但误差增大，暂不推广 |
| smol500 | 2.4630 | 28.829% | 误差明显增大且慢于已选峰值gate/up版，拒绝推广 |

这些不是全模型速度，也不是独立留出成绩。1B的gate/up MSE对应原Q8局部hidden误差约3.83%，全部矩阵扩展后约6.83%；500M相应扩展达约28.83%。不能只看对导出常量的低误差就宣称量化质量合格。

## 限定MLP的下一候选

1B只在gate/up之外增加down的DFP MSE，不改Q/K/V/O或敏感FP16。两层50次API平均3.6103ms，执行门槛通过；相对原Q8局部hidden L2 5.057%。相比gate/up MSE约3.7602ms有小幅机会，但不是全模型收益，也未接受质量。

完整24层1024＋32试验已拒绝：导出常量执行门槛通过，但原Q8开发PPL比1.087947（上限1.05），logits L2 24.606%。不进入五轮提速排行，保留原gate/up候选；局部通过不足以推广down量化。

## 1B完整模型五轮解码收益

512历史＋64新增、全24层、128次预测，两端同为t32和grouped head、中温55–<65°C起测。冻结反馈相同，各自完整诊断logits先复现；正式性能不写大logits。

| 项目 | 基线NPU | DFP MSE候选 |
| --- | ---: | ---: |
| decode token/s | 14.031768 | 15.002971 |
| 引擎首token s | 0.982023 | 0.972651 |
| 总响应 s | 10.033660 | 9.437075 |
| 驱动分配 MiB | 828.16 | 760.14 |

decode中位提高6.92%，配对五轮收益范围6.56%–7.14%，5/5更快。decoder API下降，head API基本不变，收益确实来自decoder路径。

相同场景已测CPU Q8约18.25 token/s，候选仍未追平；CPU配置搜索继续，不能把超过旧NPU写成超过CPU。原Q8对齐、独立留出、其他输入档位及稳定性均需继续。

## 500M完整32层五轮结果

512历史＋64新增、全部32层、完整输出头、128次固定轨迹预测，中温交替五轮。此模型采用峰值DFP缩放；1B采用MSE缩放，不能混作同一数值方案。两端均t32，head设置相同。

| 项目 | 基线NPU | DFP候选 |
| --- | ---: | ---: |
| decode token/s | 18.062412 | 20.487474 |
| 引擎首token s | 0.935668 | 0.921635 |
| 总响应 s | 7.966700 | 7.120799 |
| 驱动分配 MiB | 702.45 | 607.73 |

decode中位提高13.43%，配对收益12.38%–13.83%，5/5更快。驱动分配减少94.72MiB；decoder API下降，head基本不变。

全模型导出常量门槛通过：L2约3.756%、最低cosine0.99648。相对原Q8开发轨迹logits L2约12.17%、最低cosine0.96548，PPL比0.99030；不能用预测相同或开发PPL较好替代独立留出验收。

同场景优化CPU Q8五轮约22.780 token/s，NPU约20.487，仍未追平。其他新增长度、1024历史和独立质量继续验证。

## 后续布局与缩放候选

转置历史K布局：两层50次API均值3.7602→3.8107ms，耗时变化+1.35%；相对原Q8局部hidden L2 3.833%。布局改动没有测得提速，暂不扩展整栈。

限制MSE缩放搜索额外小数位最多＋1：两层50次API均值3.7602→3.5741ms，耗时变化-4.95%；相对原Q8局部hidden L2 2.861%。仅依据权重自身误差选择，不使用独立留出；完整24层decode与prefill16已编译，待实板验收。

cap1完整模型状态：`complete-development-trial`；场景1024＋32。
执行门槛：True；原Q8开发KL=0.008463，PPL比=1.028968。
完整五轮：decode 14.759158→15.228567 token/s；首token 0.632731→0.627814s。新权重仍需独立质量验收。
中位提升+3.18%；配对+2.70%–+3.83%，5/5更快。驱动762.13→730.74MiB；127次decode的decoder API 6.232042→5.970406s，head API 2.153027→2.154293s。

cap1另外复核1024＋64；32新增通过不代表64通过：

- cap1-productwide-intern1b-h1024-n64：complete，执行门槛True。

探针3次预热后记录50次；只统计VIP API，不含完整模型宿主代价。开关分时执行、温度不同，不以微小差异宣告提速。SRAM设置返回成功仅证明接口接受，不证明实际预载字节数；最终仍须同温档、全深度五轮A/B。

A8候选仅在选中的W8 gate/up矩阵输入前插入显式转换，原权重、外部KV、残差和矩阵输出格式不变。默认保持原校准动态范围；range1另将范围缩小1bit，须额外验证饱和风险。该变化不是新的权重量化算法，局部通过也不能替代完整logits和独立留出。

实测gate/up A8无可见速度收益，hidden局部L2达9.42%、另一V输出达7.39%，超过5%门槛，拒绝。后续DFP候选保持W8位数和A16，单独比较单尺度权重与逐通道权重；必须另查原权重误差，不能只依赖导出常量参考。
