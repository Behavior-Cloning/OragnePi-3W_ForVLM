# 逐token幅度归一化：真实NPU输入重放结果

新路径保留了整数down的主要速度收益，显著减小固定system首token的截断误差。它仍不是无损方案，也未通过完整模型中文输出或100ms目标验收。

## 口径

C1280/M16、层2/3 fused两层；34原NPU上游hidden/KV窗口，31个唯一输入SHA、528有效行，16padding行排除误差。只有两条旧开发prompt；首token两行实际上相同输入重复。每个窗口独立运行原始、range16、新row-scale；两处pos0另原始after。1预热+2计时，共104进程、104预热+208纯API计时。所有candidate输入均来自原模型轨迹，不包含候选传播历史。

完整目标口径保持system正文59/123+模板5=64/128，动态正文64/128/192/256+模板8，实际new72/136/200/264，仅复用system KV。本表16查询行是内部批大小，不能当作完整动态输入；没有模型首token计时、语音/RAG、视觉或真实电机。

## 完整性与资源

34原始结果与既有原NPU历史逐字节一致；两个A/A逐字节一致；104进程的16实际SDK端口全同；全部F32有限、同输入重复无变化、104次driver释放0。回收归档/原始输出/源码/输入SHA和请求顺序完整核对通过。

采样及探针前后观测最高温43.214°C，最低MemAvailable 3417.14MiB，swapin/out增量均0。这是有界算子试验，不代表长时间整模稳定性。
