                             [--save-trace-db SAVE_TRACE_DB]

optional arguments:
  -h, --help            show this help message and exit
  --model MODEL         Network model input file.
  --model-data MODEL_DATA
                        Network coefficient input file.
  --model-quantize MODEL_QUANTIZE
                        Quantized tensor description file.
  --output-path OUTPUT_PATH
                        output filename or path
  --customer-lids CUSTOMER_LIDS
                        Specify which node map to customer node by the
                        lids,and also can reframe the graph and node. Has a
                        higher priority than "--customer-ops"
  --customer-ops CUSTOMER_OPS
                        Specify which op map to customer node by the op
                        name,Has lower priority than "--customer-lids"
  --with-input-meta WITH_INPUT_META
                        Merge input meta into network.
  --postprocess-file POSTPROCESS_FILE
                        postprocess definition file
  --optimize OPTIMIZE   Optimizer for network.
  --dtype {float,float16,float32,quantized,quantized_strict}
                        Export with data type. type float means floa16
  --save-fused-graph    Wehter to save fused graph.
  --pack-nbg-unify      pack binary graph for unify driver.
  --viv-sdk VIV_SDK     If pack nbg given, please specify vid sdk.
  --build-platform {make}
                        build platform for network case, support make only
  --target-ide-project TARGET_IDE_PROJECT
                        target ide for network case, in linux64 and win32
  --batch-size BATCH_SIZE
                        Batch size for export model.
  --force-remove-permute
                        Try force remove permute of graph IO.
  --save-trace-db SAVE_TRACE_DB
                        For generating trace DB json.
