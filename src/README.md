# 应用源码

后续机器人代码统一放在本目录，与 `../docs/` 的设计调研使用同一个 Git 仓库。
`vlm_chat/` 是 SmolVLM 图片对话网页和 API 网关，支持图片、多轮问答和本地历史。
安装与使用见 [部署文档](../docs/SmolVLM网页部署.md)。
板端 NPU 复测工具位于 `../scripts/opi-npu-test`。

按实现进度逐步添加模块，不提前锁定语言或框架：

- 采集：相机、同步音频、时间戳。
- 感知：VAD、声源方向、人物检测/跟踪、音画融合。
- 统一大脑接口：本地/远端 VLM，输入关键帧与文本，输出结构化意图。
- 动作：单步模型后端、骨骼序列、重定向和轨迹约束。
- 设备与调度：MCU 通信、模型队列、状态与故障处理。

模型权重存放在被忽略的 `../models/`；模型下载来源、版本、许可证和校验值应写入
受版本管理的文档或清单。密码、令牌、个人设备配置存放在被忽略的 `.env` 或
`../configs/local/`，提交时只提供不含真实秘密的示例。
