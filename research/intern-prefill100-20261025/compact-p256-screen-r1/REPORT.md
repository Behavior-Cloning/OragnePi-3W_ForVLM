# past256 两层形状筛查

结论：M32从past448降至256有约9.1%纯API收益；M64/past256每次约15.67ms，高于past128的13.80ms，但吞吐优于两次M32/past256的简单算术和。后者不是串行两块实测，不能据此宣布整模提速。已继续独立完整24层双bank试验；此报告本身不升级最快指针。
