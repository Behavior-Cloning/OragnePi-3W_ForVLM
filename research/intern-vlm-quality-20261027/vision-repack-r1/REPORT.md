# CPU视觉Q8重排优化：约4.28秒→2.26秒

同一新binary、相同Q8文件、224×224、64视觉token、CPU6/7两线程，off-before→on→off-after。每组一预热两热样本；热中位4286.2→2256.4→4281.3ms，约1.90倍速度、延迟减少47.3%。不是长期P95。编译器日志的source git unknown不表示模型版本未知，冻结源/patch/binary SHA见source.json、build.json、snapshots。

## 具体改变及证据

原CLIP loader只分配默认CPU buffer，未走CPU_REPACK。新增显式开关OPI_VISION_Q8_REPACK，为支持的144个Q8线性权重使用CPU_REPACK，其余张量保持默认buffer；只改变加载/内核选择，不重新量化权重文件。ARM NEON+dotprod资格、重排张量数144都有运行时检查，旧默认路径保持。

并非无损变换：新旧视觉向量relativeL2约4.76%/7.74%、cosine0.99887/0.99703；前后关闭重排时输出同字节。不同矩阵内核/激活处理可改变数值，不能宣传只是改存储所以结果必然一致。此对照支持“原视觉加载路径未使用更快重排内核”是一个可修复性能因素，未把旧Q8慢于FP16的全部开销逐算子归因。

RSS峰值按前/开/后约342.0/343.3/341.9MiB；全过程最高57.412°C，顺序运行不能当独立温度改善。无功耗实测，未报告PSS。加载时间受页缓存影响，不能当重排冷加载加速。
