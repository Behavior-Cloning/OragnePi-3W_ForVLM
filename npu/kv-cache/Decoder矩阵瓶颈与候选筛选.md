# Decoder矩阵瓶颈与候选筛选

2026-10-13。以下为局部诊断，不能当成完整模型速度或产品验收。输入来自InternVL3-1B全部24层、512历史＋32新增、128步固定反馈运行中的位置544。

普通第0/1层的5份硬件计数：fullconnect占累计busy cycles中位91.555%（91.544–91.566%）。主要大矩阵为MLP gate/up/down。重复编译器UID保留候选层标签，不猜测具体层归属。

这是这一组普通层的归因，不能外推敏感层或500M；busy cycles不能直接相加当成端到端耗时，read counter也不是独立实测DDR带宽。

## 完整DFP候选：精度尚未接受

1B、512＋64、全部24层和完整输出头：导出常量执行门槛通过，但相对原Q8的完整logits L2约12.60%、开发轨迹PPL比1.05738，超过预设1.05质量线。诊断运行写大logits，速度不列为正式成绩；不推广这一候选。

下一版保持W8/A16，只用权重自身搜索DFP小数位，最小化权重均方误差；不查看留出对话。每矩阵记录全部候选的误差和截断比例。既有敏感层、head与KV格式保持基线来源；新版本仍须全模型验证。

MSE缩放版完整24层已验证：执行门槛通过，L2 4.926%、最低cosine 0.996483；相对原Q8开发轨迹PPL比0.991242、logits L2 9.608%。该结果不等于独立留出通过，五轮干净测速另列。

500M局部probe-gateup-w8dfp：50次两层API平均2.4042ms，执行门槛通过。完整32层仍需验证，不与1B混合计算收益。

500M局部probe-gateup-w8dfp-mse：50次两层API平均2.6762ms，执行门槛通过。完整32层仍需验证，不与1B混合计算收益。

## 1B完整模型五轮解码收益

512历史＋64新增、全24层、128次预测，两端同为t32和grouped head、中温55–<65°C起测。冻结反馈相同，各自完整诊断logits先复现；正式性能不写大logits。

| 项目 | 基线NPU | DFP MSE候选 |
| --- | ---: | ---: |
| decode token/s | 14.031768 | 15.002971 |
| 引擎首token s | 0.982023 | 0.972651 |
| 总响应 s | 10.033660 | 9.437075 |
| 驱动分配 MiB | 828.16 | 760.14 |

decode中位提高6.92%，配对五轮收益范围6.56%–7.14%，5/5更快。decoder API下降，head API基本不变，收益确实来自decoder路径。

相同场景已测CPU Q8约18.25 token/s，候选仍未追平；CPU配置搜索继续，不能把超过旧NPU写成超过CPU。原Q8对齐、独立留出、其他输入档位及稳定性均需继续。

## 500M完整32层五轮结果

512历史＋64新增、全部32层、完整输出头、128次固定轨迹预测，中温交替五轮。此模型采用峰值DFP缩放；1B采用MSE缩放，不能混作同一数值方案。两端均t32，head设置相同。

| 项目 | 基线NPU | DFP候选 |
| --- | ---: | ---: |
| decode token/s | 18.062412 | 20.487474 |
| 引擎首token s | 0.935668 | 0.921635 |
| 总响应 s | 7.966700 | 7.120799 |
| 驱动分配 MiB | 702.45 | 607.73 |

decode中位提高13.43%，配对收益12.38%–13.83%，5/5更快。驱动分配减少94.72MiB；decoder API下降，head基本不变。

全模型导出常量门槛通过：L2约3.756%、最低cosine0.99648。相对原Q8开发轨迹logits L2约12.17%、最低cosine0.96548，PPL比0.99030；不能用预测相同或开发PPL较好替代独立留出验收。

同场景优化CPU Q8五轮约22.780 token/s，NPU约20.487，仍未追平。其他新增长度、1024历史和独立质量继续验证。

探针3次预热后记录50次；只统计VIP API，不含完整模型宿主代价。开关分时执行、温度不同，不以微小差异宣告提速。SRAM设置返回成功仅证明接口接受，不证明实际预载字节数；最终仍须同温档、全深度五轮A/B。

A8候选仅在选中的W8 gate/up矩阵输入前插入显式转换，原权重、外部KV、残差和矩阵输出格式不变。默认保持原校准动态范围；range1另将范围缩小1bit，须额外验证饱和风险。该变化不是新的权重量化算法，局部通过也不能替代完整logits和独立留出。

实测gate/up A8无可见速度收益，hidden局部L2达9.42%、另一V输出达7.39%，超过5%门槛，拒绝。后续DFP候选保持W8位数和A16，单独比较单尺度权重与逐通道权重；必须另查原权重误差，不能只依赖导出常量参考。
