# 完整 Intern I16 range16：独立结果审计

结论：原始证据完整，计时可用于该 C1280 配置的配对比较；候选确实降低了 prefill/TTFT，但整模数值与行为门控失败，不应替换当前模型。100 ms 目标未达到。审计仅读取 Windows/WSL 回收证据，未访问板卡。

## 数据与公平性

- rc0、meta complete；72 次固定反馈性能、72 次自然输出、24 次诊断请求（96 步完整词表 logits）、3 次正常 close；无 error/release_error。不是 72 个独立语义场景：自然集为 12 场景 × 2 system × 3 版本。
- 原图→候选→原图；相同 runtime SHA、CPU affinity、C1280/M16、group/mask/greedy 参数。29 个图/embedding 文件的记录 SHA 与冻结配置一致，只有 prefill-layer2.nb 变化；原图重复映射完全一致。候选替换 fused layers 2/3 的 prefill，两处 sensitive down 权重及输入网格变化；不是等值或全模型 INT16。
- 性能输入与旧 fullbaseline 完全一致；自然输入与旧 semantic24 完全一致。system 正文59/123加模板5＝静态64/128；动态正文64/128/192/256加模板8＝实际新72/136/200/264。最长输入392，固定输出32最多使用423位置，容量充足。
- 每条先 reset 并构造本版本 system KV，随后热请求仅复用该固定前缀；无动态 KV 预计算。system 构建排除 TTFT，但计入全段资源。不同版本不共享数值 KV。
- 所有72条性能请求 scalar_prompt_tokens/seconds 均为0；末8行用 padded M16，非 scalar8，也非真实M8。真正有效行数及新增KV仍为正文+8。
- 性能生成32个预测，使用相同固定反馈；计时不写 logits。decode 是31个首字后间隔。自然上限32、正常 EOS；诊断另跑4步固定反馈，明确排除速度统计。

## 全模型数值与行为

24份原始 f32 文件共58,242,816字节，逐份实际重算SHA、检查全部有限值及4×151674形状；每步 argmax 与记录 token 一致。

- 原图 A-A：24/24固定反馈全序列、24/24自然全序列、8/8完整4步 logits 文件逐字节相同。
- I16：固定反馈全序列0/24相同，首 token 9/24相同；诊断 top1 为23/32步相同，完整 logits 相对L2误差45.57%–53.32%，最大绝对差11.0137。这里的相对L2跨整词表/4步，不是任务错误率。
- 自然序列仅2/24完全相同，首 token 4/24相同；含EOS输出中位5→13 tokens。4条达到32上限，3条明显停在未完句，另1条虽触及上限但句子已完整。

这比单块FP32派生历史输入上约0.3%的 hidden误差大得多。单块开发集不能代表真实 NPU 历史/KV 与后续24层累积影响；本报告不凭此定位具体层内根因。

## 结论边界

这是 Intern NPU 文本路径，合成WAV语音前端和RAG常驻；固定LLM fixture不由ASR文本触发。没有视觉编码、真实麦克风或电机。旧semantic集已用于range调参，历史 independent_holdout=true 字段本轮失效；新 independent-household-v2 尚未测试。当前候选只保留为诊断实验，不晋升；先定位真实NPU中间激活/量化失配，再重新做数值、语义和执行器兼容性门控。完整机器结果见 INDEPENDENT_AUDIT.json；independent_audit_recompute.py 是数值重算脚本，人工判定另保存在JSON。
