# Down 异常通道离线筛查独立审计

结论：源码、输入来源、场景划分和结果记录一致性通过；不批准部署、不批准冻结异常通道名单。审计只读取 WSL 文件，没有重新执行模型、SDK 或板卡。原始激活/投影未保存，因此本文重算的是已记录指标的汇总与一致性，而不是独立重跑全部数值。

## 样本与分割

48 窗口 = 12 场景 × 2 种 system × 首/末 32 行；24 个 calibration、24 个 heldout。按场景名 SHA 排序固定 6/6 分割，同场景的首末窗口及两个 system 不跨组。48 个输入 SHA 均不同，528 个输入段按实际 graph 顺序、形状、有限值、历史空槽及因果 mask 复核通过。历史最小为 64，窗口路径没有 system pos0。

这些是此前已经用于 range16 调参的开发集。heldout 仅表示没有参与本次通道排序，不是整个工程的独立测试集。三个 D256 场景全部落在 heldout，calibration 没有 D256。两组共用固定 S64/S128 前缀，不能用前缀覆盖结果证明新 system 泛化。查看 heldout 后选择 K/range 也会把它转为开发数据。

## 公式与形状

两个 down 输入均为 `[48,32,4864]`，权重 `[4864,896]`，两个实际 bias 均全零。激活/权重先 round 到 FP16 再以 FP32 存储；权重 I16 fractional bits 分别为 L2=16、L3=15。通道分数是 calibration 跨样本/位置的绝对值最大值，不使用 heldout 激活排序。

预测为 `Q(X)Q(W) + X_selected W_selected - Q(X_selected)Q(W_selected)`。实数代数上等于选中通道保留 FP16 数值、其他通道 I16 近似；实际三个 FP32 乘加的舍入顺序不同于 NPU 分支/合并。误差参考是 FP16-rounded X/W 的 FP32 投影，没有模拟输出量化或 residual。忽略 bias 只因两个实际 bias 为零。

窗口 clip 是 round 后超出 `[-32768,32767]` 的元素数，屏蔽选中通道，不是超界通道数。标称 ±8/±16 的正上限分别少一个 LSB。full-position 使用 `abs(x)>range`，只是幅值阈值计数，不能当作同一 clip 指标。

## 全位置补测

24 个完整 prompt，总计每层6336个位置：system2304、dynamic（正文+模板）4032，覆盖全部 S64/S128、正文64/128/192/256。`finish` wrapper 捕获 down 输入，返回原 `finish` 输出，并对重构输出执行零容差断言；闭包绑定各自原函数，没有循环晚绑定。它运行前四层源 Q8 的 FP32 完整因果注意力，不能与窗口 imported-graph FP32 路径合并数值。

L2 prefix 最大幅值2013.62854，calibration 首通道813；L3 prefix 最大1180.65051，首通道2247、第二通道3016（745.92780）。range16 超界前缀通道 L2 为813/3250/4376，L3 为2247/3016。Top4 可覆盖这里已记录的 range16 超界元素，但固定前缀重复出现在两组，不代表异常处理泛化。dynamic 部分两层全部小于16（各自最大9.32511、10.67965）；range8 的 L3 heldout Top4仍留下6个幅值超界元素，Top8在此开发集上清零。

补测逻辑覆盖每个位置，但文件仅保存 prefix/dynamic 聚合，没有每个位置的原始激活或最大值索引；本审计不能仅从该文件独立定位极值到具体 pos0。与先前真实 NPU 首段诊断相符只能作为旁证。通道排名与只取动态首末窗口的第一轮明显不同，本身说明采样范围会改变名单。

## 边界

没有真实 NPU KV、内部累加/分支舍入、输出量化、24层 logits、自然语言动作质量、时延、并发负载或长期稳定性证据。未保存 raw 激活与软件版本使精确复算有限。本次仅支持后续受控研究，不能替代全模质量门禁或完整动态64–256的100ms目标。
