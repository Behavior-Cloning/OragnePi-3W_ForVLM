# W16 Conv M32 独立结果审计

审计通过，候选在此单块配置没有速度收益。直接重算原始 30 次 API 时间，未导入主分析器、未访问板卡。

| 项目 | A 前 | W16 Conv | A 后 |
|---|---:|---:|---:|
| P50 API (ms) | 10.8661680 | 13.1410940 | 10.8389805 |
| P95 API (ms，线性分位) | 10.8762327 | 13.1608946 | 10.8509315 |

候选比 A 前慢 20.9359%；A 前后 P50 漂移 -0.2502%。每组 3 次预热、30 次计时；无 NPD/IO profile 混入。

五端口共 45,056 个 f32 全 finite，三份输出逐字节相同；SHA256 `2c99a1b67cc752dff7b8eecd065424cb194bfe604ab59bd2020f3a525aa179d3`。这说明同输入的候选与原 NPU 输出一致，不等于与 FP32 oracle 完全一致。原与候选实际 NB 16 端口元数据原始文件也相同。

候选驱动分配 45,351,216 B，较原增加 17,996,544 B。三组释放后和 post-health driver 均为 0。9 个资源样本最高 40.548°C，可用内存最低 4,621,918,208 B。

来源/候选 NB、canonical input/reference、fixture metadata、控制器/runner/probe SHA 均核对通过。W16 是 I8 整数码符号扩展到 I16 存储，不能称原始权重存储字节相同。

边界：仅 C512/M32、L0/1 两层融合块、一个 canonical 输入的 API。排除了加载与转换，未驻留语音/RAG，不能据此报告整模 TTFT、长稳或其他 M 批次的性能。
