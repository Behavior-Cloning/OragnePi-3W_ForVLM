# C512/M32 逐行归一化 down：独立静态审计

静态文件契约通过；没有板卡、SDK、编译或推理调用，不批准数值质量、速度或默认部署。候选 NB SHA：f0bebd8b9489f487a5b72658184c9d8f90bb8ec36a6682afde9bb61e097ea25a（29,765,440 B）。

源图为 C512/M32/L2 的已有 range16 I16 down。独立回退新增节点/重接输入后，graph 与源图完全相同。只新增每层 abs → reduce-max → clip → divide → restore-multiply，共 10 节点；两个既有 I16 converter 输入转接到归一化值，fl 改为14，两个 FC 输出改 FP16。其他旧图/量化键保持原值。

生成 C 确认 reduce 对 [4864,32] 的 axis0 求 max，得到 [1,32]，按 token 独立归一化；divide 广播为 [4864,32]，restore 广播为 [896,32]。scale clip 为 [2^-14,65504]，中间新 tensor 为 FP16；归一化结果经 I16 DFP fl14 后送原 FCL，FC 输出与还原乘法为 FP16。每条生成 C 连接已独立逐项核对。改变 FC 输出精度也删除了两处原生成输出 DATACONVERT，属于预期改变。

16 个外部 normal tensor 生成 C 属性、IO 顺序和 nbg_meta 全等。这里是生成文件核验，实际 SDK 端口属性尚待 probe 在运行时记录。

在实数代数、有限输入且 bias=0 下，s·((x/s)W)=xW；本候选实际两个 bias 均为0，必要条件成立。实际 FP16 divide/FC输出/乘法、I16 fl14 舍入、此前 I16 权重误差以及 NPU 累加仍会产生误差，不是数值无损。fl14 可表示 [-2,1.99993896484375]，归一化峰值不大于1；实际特殊值、下溢清零、累加溢出均未通过编译成功证明。

离线误差结果是两条复用 prompt 的真实原NPU激活，配 FP32 矩阵计算及指定 FP16 边界，不是 NPU 内核模拟器。十个新增算子可能增加开销，离线误差变小不能推出提速。后续必须先同输入 NPU replay（含pos0/AA/finite/端口），再谈整模传播、自然语义、system缓存、真实延迟和资源。完整100ms目标仍未达成。

## 本次 C512/M32 增量

新增10个局部节点及14个有关量化键，与此前 C1280/M16 row-scale 完全一致；整个导出常量payload亦一致。11输入/5输出几何另行字面核验：hidden[1,32,896]，KV history[1,2,512,64]，mask[1,1,224,544]，rope[1,1,32,64]，新KV输出[1,2,32,64]。不能把旧C1280/M16板测直接算作本版实测。

本候选以既有range16 I16 down图为来源。“权重相同”只表示相对该I16来源不再变化；与原精度C512/M32基线相比，两处down矩阵已经是I16量化，需要整模配对质量门禁。后续若和原true M8尾块结合，尾块是否保持原图、system准备/动态调度、缓存复用都属于运行时合同，未由本静态审计验证。
