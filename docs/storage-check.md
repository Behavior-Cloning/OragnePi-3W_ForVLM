# 板载存储核对

官方 Zero 3W 产品页规格：

- eMMC：8/16/32/64/128GB 可选，默认空焊
- UFS：32/64/128GB 可选，默认空焊
- TF 卡：支持最高 128GB

官方底面产品图中，右侧可以看到 eMMC/UFS 对应的 BGA 焊盘区域，没有安装存储芯片。这个图是标准产品展示图，不能替代对具体订单 SKU 的确认；只有订单明确写出 `eMMC xxGB` 或 `UFS xxGB`，才应认为买到的是带板载存储版本。

6GB 只表示 LPDDR5 运行内存，不表示 eMMC/UFS 容量。

## 当前 TF 卡实测（2026-10-08）

- 识别：SanDisk（MID `0x03`、OID `SD`），64GB 标称容量，系统可用原始容量约 59.5GiB
- 卡内 SD Status：Class 10、U3、V30、A2；SD 标准没有 A3，卡面若像 A3，通常是把 `A2` 和 `U3` 记混了
- 总线：UHS-I SDR104、4-bit、1.8V，当前时钟 150MHz
- 只读顺序速度：约 67.7MB/s
- 512MiB `oflag=direct` 顺序写：约 57.2MB/s；临时测试文件已删除
- 测试后没有发现 MMC I/O 或 ext4 错误

这个性能足够作为系统盘、加载模型、保存普通图片/音频和单路压缩视频。A2
重点代表随机 I/O 能力，U3/V30 代表至少 30MB/s 等级的持续写能力。长期多路录像、
高频数据库或 ROS bag 连续采集时，卡的写入寿命比峰值速度更关键，量产方案宜改用
High/Max Endurance 卡或 USB SSD。
