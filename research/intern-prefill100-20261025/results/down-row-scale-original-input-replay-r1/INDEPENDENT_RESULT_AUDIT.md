# Row-scale 原 NPU 输入重放：独立审计

原始证据与局部测量完整性通过；逐行归一化大幅缓解本组首 token 异常，但不是整模型质量或 TTFT 达标证明。没有板卡/SDK/锁操作，本审计只读取回收文件并生成审计文档。

## 证据完整性

控制器 rc0、meta complete。34 个输入窗口、31 个唯一输入 SHA、2 条 prompt；104 个独立 probe 进程，严格原始 → 旧range16 → row-scale，两个pos0增加原始after。208 次有限正数纯 API 时间、104 次预热、104 次driver释放归零。104份实际F32共9,371,648字节，全部finite；逐份SHA及16个实际SDK端口字面合同验证通过。

34 原始输出与历史原 NPU 输出逐字节相同，两个 A/A 逐字节相同。319 个归档常规文件与回收内容SHA对应；NB、binary、输入及冻结源码均核对。配置解析完全相同；runner只省略上传JSON最后一个换行。新controller已绑定独立静态审计及候选NB/graph/quant SHA，分析器新增精确有序唯一事件、几何、计时门禁已经独立复核。

528有效行划分为首token2行、首块其余30行、后续system160行、dynamic+template336行；16padding行只从误差分区排除，历史/AA对照包含全部输出。两条首token行是同一底层例子的重复，并非两种独立异常。

## Hidden 局部误差

relative L2以同窗口实际原NPU输出为参照：

|分区|行数|旧range16|row-scale|
|---|---:|---:|---:|
|首token|2|99.416719%|0.120553%|
|首块其余|30|31.020028%|0.419854%|
|后续system|160|0.338466%|0.317985%|
|动态+模板|336|0.320797%|0.297808%|

首token hidden最大绝对差1893.5625降为0.287109375；首块其余最大绝对差1.6015625降为0.01171875。但动态hidden并非所有指标改善：整体relative L2降至0.297808%，最大绝对差却由0.01171875增至0.015625。

L2 K/V在所有行均逐字节不变；L3 K/V有变化。首token L3 V relative L2 从452.191%降至1.81846%，其绝对差仍0.00427246094；不能只报告hidden而遗漏KV误差。动态 L3 K/V relative L2为0.0188535% / 0.0460571%。全部五端口、各窗口和分区详情保存在JSON。

每个窗口仍注入原模型的上游hidden/KV，候选错误不会跨窗口累积。首块其余行包含块内注意力传播影响，不能视为完全独立的正常token量化误差。本轮不能判断完整候选生成质量或长期KV误差累积。

## 资源与结论边界

231个周期采样、59.271秒；监控峰温43.214°C（probe边界40.920°C），最低MemAvailable3417.141MiB；整机8核busy约9.10%。SwapUsed固定932MiB，换入/换出和OOM计数增量均0。driver前后0且每个进程释放0；tmpfs最低空闲1,989,591,040B，仍高于1GiB+100MiB保留线。CPU频率记录不是NPU频率；没有PSS归因或长时间稳定性结论。

本轮支持“逐行归一化能缓解已观察首token异常”这一局部结论。完整模型需要新的同场景logits、自然语义、缓存传播、性能及资源比较，不能将18.34ms的两层块时间作为完整动态64～256输入≤100ms的证明。**完整目标尚未达成；不批准默认部署。**
