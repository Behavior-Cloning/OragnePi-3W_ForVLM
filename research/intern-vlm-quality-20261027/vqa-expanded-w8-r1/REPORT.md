# 家居陪伴场景：112×112 / 224×224 NPU W8 配对测试

2026-10-27。60题、50张公开COCO照片，问题与参考在推理前冻结；每类10题。两个方案均使用原生2×2 pixel shuffle和原投影结构，分别输出16/64视觉token。每组3次视觉预热＋60次热编码、60次NPU语言问答。

**核心事实准确率：112为18/60（30.0%），224为40/60（66.7%）。** 112暂不用于陪伴决策；224是优先继续评估的候选，仍有明显错误，不晋升质量合格默认版本。

CPU是/proc/stat按8核总容量归一化，含其他系统进程；并非单进程百分比。视觉每0.5秒采样，语言每请求前后采样，不是温度峰值的连续保证。RSS不能代替驱动分配，两者不能随意当作完整内存总和。SwapFree只反映存量；语言请求区间的全机vmstat差分如下，不能归因于单一进程。

语言区间pswpin / pswpout：112 845 / 0页，224 3372 / 0页；两区间oom_kill增量均0。存在少量swap-in，不是完全无swap环境。结束后MemAvailable约2.23GiB，但swap存量仍约2.76GiB；不是把这些swap都算成本次模型占用。

## 版本与边界

W8是144组ViT FC权重per-channel INT8；图边界INT16，敏感norm/GELU FP16，stem/projector保留原精度。不是全W8A8，不等同CPU GGUF Q8_0。完整26张视觉图及语言计算在NPU，JPEG预处理和数据转换在CPU。112/224为现有InternVL3-1B-Instruct权重与位置插值适配，并非官方112精度承诺。此实验未隔离分辨率与量化各自的精度损失。

固定数据SHA：`da699afb82011387b898b5d9fc52af1601a8842c10301fb46a858a6e6ad15b56`。源编译、图SHA、二进制SHA分别见build-status.json、config-112/224.json、binary112.json、upload-sha256.json；推理输入及实际token见vqa-frozen-112/224.json。评分grades.json、原输出、资源日志保留。原始大模型/向量/图片留Windows不入Git；报告图片在Mac镜像可打开。

下一步优先在224分辨率修复位置关系与局部目标识别，加入更多真实家居相机画面，并做同图INT16/W8对照；112只保留实验版本。任何后续优化须保持本套冻结输入，另起版本记录，不能用改题后的分数覆盖本次结果。
