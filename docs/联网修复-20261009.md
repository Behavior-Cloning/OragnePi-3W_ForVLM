## 修改

- 保留 Robot_Z1 密码配置，但设 `autoconnect=false`、优先级 -100，避免再次回连旧热点。
- professional-EXT5G：自动连接、优先级 999、`autoconnect-retries=0`（持续重试）。
- 新连接使用永久 MAC、`powersave=2`（关闭 Wi-Fi 省电），保持 DHCP。
- `opi-wifi-country.service` 在 NetworkManager 前执行 `iw reg set CN`。
- `opi-network-diagnostic.service` 开机最多记录约 4 分钟的网络状态；成功连接目标 SSID
  且获得 IPv4 后提前结束。日志写入 `/var/lib/opi-network/boot-network.log`，
  前一次日志为 `.previous`，权限 0600，不使用 `--show-secrets`。
- 原网络配置保存在板端 `/root/network-backup-20261009-1733/system-connections/`。
- SSH 原本已启用，不修改登录配置；未设置可能冲突的固定 IP。
