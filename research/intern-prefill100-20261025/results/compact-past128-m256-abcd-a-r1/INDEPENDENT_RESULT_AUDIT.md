# Compact past128/M256 五组独立结果审计

**本输入下，compact plain 两层块纯 API P50 为83.434 ms，比C512原图下降60.40%；仍非完整模型100ms达标。** Compact后再加row224反而慢12.45%，因此不能把两条优化的收益直接相加。

原始归档所有成员、实际NB/输入/新探针/运行源码SHA核验通过，控制器rc0、meta complete，无监控错误。五组统一新probe，每组3warmup+30纯API，共150样本、15warmup、5次释放0。API计时只覆盖vip_run_network，加载、转换、显式flush/invalidate均在计时外；NPD/IO profile关闭。新probe在C512 plain和row224上都逐字节复现旧probe归档输出。

35.52秒窗口共138条资源样本：最高41.54°C，最低MemAvailable3729.16MiB；全八核CPU加权平均约5.99%，swap919.75MiB恒定，换入/换出均0。前后driver0，tmpfs最低剩余2,338,467,840B，启动空间/内存预留通过。无语音/RAG并发，无长稳定性结论。

C128指专用图past输入容量，不是整个KV存储上限。当前仅L0/L1融合两层，history来自FP32参考而非真实NPU缓存。完整系统仍须处理24层、prefix-only缓存、动态正文64/128/192/256+模板、后续history超过128的回退，并验证自然中文输出与动作冲突。不得把这一个83ms块冒充完整prefill/TTFT≤100ms；也不能推定多个块简单相加就代表实际整模延迟。

本审计仅Windows/WSL回收文件，无板卡、SDK或测量源码修改。冻结来源及逐端口证据见 `INDEPENDENT_RESULT_AUDIT.json`，图/fixture源审计见 `graphs/compact-past128-m256/INDEPENDENT_SOURCE_AUDIT.md/json`。
