# 原 NPU 输入下 I16 局部重放：独立结果审计

审计通过仅表示本轮证据完整、统计可复算，不批准 I16 全模型部署。只读取 Windows/WSL 文件，没有访问板卡、SDK 或锁。

104 次进程严格按冻结顺序完成，含 34 个窗口各原图/旧 I16/range16，再加两个 pos0 原图复测；共 208 次 API 计时、104 次预热、104 次 driver 释放为 0。归档所有常规文件逐 SHA 核对；104 份实际 f32 全有限值；实际 11 输入/5 输出端口逐项符合字面合同。34 份原图结果与历史输出全元素逐字节一致，2 次 A/A 一致。上传配置与 runner 复写配置只差最后一个换行，JSON 完全相同。

只有两个 prompt、34 个窗口、31 个唯一输入。共 528 个有效行，排除 16 个 padding 行。两个首 token 实际是同一个底层输入的重复。KV 按 [2,16,64] 的 query 维切片，不误切 head 维。

首块其余行的较大误差与首 token 异常同时出现；这些行可受同块 attention 的前行误差影响，不能称作独立正常 token 的量化误差。后续各窗口重新使用原 NPU hidden/KV，候选历史未继续传播，因此约 0.32% 动态局部误差不等于整模 logits 或语义误差。range16 未修复首块异常；本集后续误差还略高于旧网格，不能泛化成所有输入的优劣结论。

所有组的 L2 K/V 与原图逐字节相同。range16 首 token 的 L3 K 相对 L2 约 23.5153%，L3 V 约 452.1910%（绝对最大差 1.52625，参考值较小使相对比值很大）；后续动态 L3 K/V 误差约 0.02218% / 0.06161%。全部五端口逐窗口与分组统计均独立重算，与父分析在 1e-12 相对容差内一致。

231 个资源样本覆盖 58.855 秒：温度最高 42.966°C，MemAvailable 最低 3583.016 MiB，整机八核平均忙碌约 9.008%。SwapUsed 912.5–919.75 MiB，pswpin/pswpout 均零增量，OOM 计数未增长；不能把已使用 swap 写成 0。tmpfs 可用空间最低 2,161,676,288 字节，高于 1 GiB + 100 MiB 保留线。开始/结束 driver 均为 0。无进程 PSS 采样、无 NPU 频率测量，CPU 频率不能冒充 NPU 频率。
