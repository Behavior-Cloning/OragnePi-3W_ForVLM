# 敏感FP16 down的真正I16权重候选：离线初筛

这与旧W8整数码扩展为I16存储不同：从原decoder权重的FP16舍入值重新生成I16 DFP整数码，属于新的量化精度候选。尚未验证导出payload字节对应、激活校准、SDK可执行性、NPU速度和完整模型质量，不替换默认图。

两处down的全tensor对称DFP权重relative L2：I8为6.769%/13.230%，I16为0.02394%/0.05399%，本权重范围无饱和。仅是两种简单DFP量化的离线比较，不能当现有生产I8每通道量化误差，也不能由权重误差推出logits或中文动作精度。保存实际fl、来源SHA和计算脚本。

后续必须先证明实际FP16导出常量对应；检查SDK FC支持组合，使用代表性真实输入校准两处down的激活范围，再导出独立单块，做同输入速度与五端口误差。合格后才进入完整固定反馈logits/自然中文任务，仍要求system正文59/123+模板5=64/128、动态正文64/128/192/256+模板8，新72/136/200/264，system-only KV，完整prefill和TTFT均100ms目标。不能只看少数权重误差就升级。
