# 家庭／桌面陪伴动作字典 v2

35个原子动作与20个组合技能分开检索。所有名称描述的是动作语义，当前板卡试验只做召回，不代表已有对应电机或执行器。动作按桌面限幅、原地、不接触物体的约束规划。

## 原子动作

|ID|动作|用途|
|---|---|---|
|A01|向左转头|头部缓慢转向左侧，改变视线方向，用于观察左侧目标。|
|A02|向右转头|头部缓慢转向右侧，改变视线方向，用于观察右侧目标。|
|A03|抬头看|头部向上仰起，视线移向较高位置，可表现期待或注意高处。|
|A04|低头看|头部向下俯视，查看低处目标或表达低落、困倦。|
|A05|歪头观察|头部轻微侧倾，表达疑惑、好奇，观察陌生事物。|
|A06|轻轻点头|头部小幅上下摆动，表示赞同、理解、回应。|
|A07|轻轻摇头|头部小幅左右摆动，表示否定、拒绝、不认同。|
|A08|注视指定目标|头部与视线保持朝向已定位对象，持续关注人物或物品。|
|A09|右手挥手|举起右手并往复摆动，用于见面问候或告别。|
|A10|左手挥手|举起左手并往复摆动，用于见面问候或告别。|
|A11|举起右手|右臂向上抬起并短暂停留，表示应答、示意或请求注意。|
|A12|举起左手|左臂向上抬起并短暂停留，表示应答、示意或请求注意。|
|A13|双手轻微摆动|两臂小幅慢摆，作为自然待机、轻松愉悦或温和陪伴动作。|
|A14|双臂张开|两臂向两侧展开，表达欢迎、亲近、拥抱邀请。|
|A15|拍手|双手短促合拢拍击，表达赞赏、庆祝、开心。|
|A16|双手抱头|双手移向头部并停留，表达惊慌、懊恼或受惊。|
|A17|弯腰低头|上身前倾并低头，表达鞠躬、感谢、道歉。|
|A18|恢复直立|身体从弯曲状态回到中立直立姿态。|
|A19|身体蜷缩|上身收拢，姿态缩小，表达害怕、寒冷或疲倦。|
|A20|肩膀下垂|双肩松弛下沉，表达疲惫、失落或放松。|
|A21|伸懒腰|双臂上举并舒展身体，用于醒来或缓解疲劳。|
|A22|打哈欠表情|张口缓慢闭合，表现困意、疲劳、想休息。|
|A23|眼睑下垂|眼睛半闭或缓慢合上，表达困倦、安静休息。|
|A24|睁大眼睛|眼睛张大，表达惊讶、好奇、注意新事物。|
|A25|微笑表情|呈现笑容，表达愉悦、友善、满意。|
|A26|平静表情|回到中性柔和表情，适合等待、安静陪伴。|
|A27|难过表情|眉眼下垂，表达失落、伤心或共情。|
|A28|惊讶张嘴|嘴部略张，表达惊奇、惊喜或意外。|
|A30|身体左右摇摆|上身随节奏左右摆动，表现轻松、舞动或音乐律动。|
|A31|身体稍微前倾|上身小幅前倾，表达注意、倾听、靠近观察，不发生底盘位移。|
|A32|身体后缩|上身向后收回，表达谨慎、避让或受惊，不发生底盘位移。|
|A33|右手指示右侧|右臂伸向右边，用于指出右侧方向。|
|A34|左手指示左侧|左臂伸向左边，用于指出左侧方向。|
|A35|指向指定物体|用手指示一个已定位的物体，帮助他人注意目标；不接触物体。|
|A41|保持静止|保持当前姿态，暂不产生肢体运动，用于等待、监听。|

|H09|疲倦时放松|肩膀下垂 → 打哈欠表情 → 保持静止|
|H10|陪伴做休息操|伸懒腰 → 恢复直立 → 微笑表情|
|H11|随着音乐轻摆|身体左右摇摆 → 双手轻微摆动 → 轻轻点头|

注视、指物需要外部目标定位；本词典没有开启传感器、检索文档、查看历史、修改配置、走路、跳跃或抓取。晚安、倾听等技能不含语音输出或启动ASR步骤。急停、能力不足处理属于外部执行层。

双手动作完整标记左右手影响范围。手臂或关节是否实际存在、限位与运动噪声需要后续按硬件映射确认。

原子Top-K各是一项原子素材；技能Top-K各是一整段组合。多个技能共享的微笑、点头等步骤需要在最终计划中检查重复，不能把两种词典混排后直接重复执行。
