# 独立结果审计：C512/M32 down row-scale A/B/A

审计结论：原始证据完整性与计时口径通过；候选存在实际提速，同时存在数值差异、动作语义遗漏和音频 deadline overrun。**不晋升为默认模型；完整动态 64–256 的 prefill/TTFT ≤100 ms 目标未达到。** 本审计只读取 Windows/WSL 已回收文件，未访问板卡、SDK 或运行锁。

## 数据及公平性

- 独立核对归档 SHA/size、36 个普通文件成员、24 份实际完整 f32 的 SHA/有限值/argmax，以及源码和图 provenance。72 性能、144 自然、24 诊断记录数量和唯一 case 组合正确，3 次关闭 driver 均为 0。
- 同一 runtime、C512/M32、24 层。只改变 M32 主图 prefill-layer2.nb；原始 12 个 M8 尾图和 decode/head/embedding 未改。新图有局部 I16 down 权重及行归一化，不能称整模型同精度或数值无损。
- 静态总长 64/128，包括正文 59/123 与模板 5；动态正文 64/128/192/256，模板另占 8，实际新增 72/136/200/264。每条请求 reset 后重建并仅复用 system KV；无动态 KV 预计算。true M8 尾块恰好 1 次，scalar_prompt_tokens=0。最大请求加 31 个后续反馈 token 为 423≤512。
- 计时 performance 固定 32 步 feedback，diagnostic=False；decode=31/(total−TTFT)。自然输出 max32/EOS，诊断为 4 个强制反馈步，诊断耗时不进入速度。system 重建不计 hot TTFT，但纳入整轮资源。
- 每格仅 3 场景×1 次，不能把 P95 当可靠尾延迟；本轮约 14.31 分钟，不是 15/30/60 分钟持续稳定性验收。

## 数值与自然动作

- A/A：8 份诊断完整 logits 字节相同，24/24 固定预测 token 数组相同，48/48 自然 token 数组相同。
- 候选：完整 logits relative L2=2.866%–3.220%；31/32 诊断 argmax 相同。s64-d128-0 第四步由 token100662 变 token1773，原 top1 margin=.1171875，新=.01953125，均非 tie。固定 32 步预测全数组 20/24 相同、首预测 24/24 相同。
- 自然 44/48 token 相同，development 21/24、household-v2 23/24。这是复现率，不是准确率；两组都已有调试/测试使用，不能称新独立 holdout。

全部 48 个候选回复按固定 rubric 复核：compatible 12、partial 19、safe_underresponse 9、underspecified 5、conflict 2、not_action 1。partial 表示约束省略，不自动等于不相关；保持静止也不自动等于完成运动要求。两个明确冲突仍是要求摇头却输出点头。相同回复只在原输入、gold、回复完全匹配时复用已有人工判断，4 个变化独立重审；明细与 hash 绑定见 INDEPENDENT_MANUAL_REVIEW.json。

RAG 仍不能直接执行 Top3：右转案例三个候选分别包含前后移、左右转摆、左右侧移，均与禁止动作冲突；左臂案例三个候选分别低头、双臂摆动、抬头展臂，均使用禁止部件；停止案例 Top2 中立姿态、Top3 腰右转会主动运动；左转头案例前两项为侧倾而非转头。高层回复相容不代表 Top3 联合执行安全，所有动作仍为 mock。

## 资源、音频与边界

1668 个样本：最高 50.282°C，MemAvailable 最低 2027.47 MiB，跟踪进程 PSS 合计最高 588.03 MiB（不包含全部系统/NPU 驱动）。整机 8 核 busy 加权均值约 7.58%，load1 中位 3.60、最大 3.99。CPU6/7 观测到 2.002 GHz；没有 NPU 频率证据。三组 ready 驱动分配约 979–983 MiB，close 均归零。

SwapUsed 932→1374.5 MiB；pswpin +7278 页，pswpout +120684 页。存在明显交换增长，不能称无 swap 或证明长期常驻内存无风险。全局含模型装载/切换；各 phase 子集不能相加解释全部增长，也不能把总增长都归因于候选推理。

音频最终 54669 帧，2701 帧 overrun（约 4.94%），max lag .794391 秒，max compute .794326 秒，queue 最大 1、无异常；queue=1 不等于无延迟。三组 performance phase 的 overrun 比例均约 4.9%，没有证据把全部问题单独归因于候选。语音是独立预录音流；LLM 使用固定 fixture，不是当前 ASR 文本，因此这里不是说话结束→大脑回复的端到端链路延迟。无视觉编码器、真实麦克风或电机。

已冻结 boundary20 未运行，当前 8 格不代表连续长度和全部批边界通过。候选减少 TTFT，但数值/语义/实时性与 100 ms 目标均仍有未解决项。
